# DUGHU — Internationalisation

## Objectif

Préparer Dughu à supporter plusieurs langues.

## Langue principale

La langue principale actuelle est le français.

## Règle importante

Éviter de disperser inutilement les textes utilisateur directement dans les composants lorsqu'une architecture d'internationalisation existe.

## Textes

Les textes d'interface doivent pouvoir être centralisés.

## Dates

Les dates doivent être affichées selon le contexte linguistique et régional approprié.

## Nombres

Les nombres doivent pouvoir être formatés correctement selon la langue.

## Développement futur

L'architecture doit pouvoir évoluer vers plusieurs langues sans nécessiter une réécriture complète de l'interface.

## Règle

Ne pas introduire une bibliothèque d'internationalisation uniquement pour une petite fonctionnalité sans analyser l'architecture existante.
