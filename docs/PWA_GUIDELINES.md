# DUGHU — PWA Guidelines

## Objectif

Préparer Dughu à offrir une expérience proche d'une application mobile.

## Installation

La PWA doit pouvoir être installée lorsque les conditions techniques sont réunies.

## Manifest

Le manifest doit définir correctement :

* nom ;
* icônes ;
* couleurs ;
* comportement d'affichage.

## Offline

Ne pas prétendre que Dughu fonctionne entièrement hors ligne si cette fonctionnalité n'est pas réellement implémentée.

## Cache

Le cache doit être utilisé de manière contrôlée.

Ne jamais mettre en cache des données privées sans comprendre les implications de sécurité.

## Notifications

Les notifications push doivent respecter les permissions de l'utilisateur.

## Mobile

L'expérience PWA doit rester cohérente avec l'application web.

## Règle

Ne pas transformer Dughu en PWA complète sans vérifier les conséquences sur l'authentification, le cache et les données privées.
