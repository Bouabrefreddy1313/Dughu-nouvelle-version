# DUGHU — Testing Guidelines

## Objectif

Chaque fonctionnalité doit être vérifiée dans les scénarios normaux et les scénarios d'erreur.

## Tests fonctionnels

Vérifier :

* création ;
* modification ;
* suppression ;
* affichage ;
* navigation ;
* permissions.

## Tests d'erreur

Tester notamment :

* utilisateur non connecté ;
* API indisponible ;
* réponse serveur invalide ;
* données incorrectes ;
* permission insuffisante ;
* ressource inexistante.

## Tests responsive

Vérifier :

* 320px
* 375px
* 390px
* 768px
* 1024px
* 1280px
* 1440px
* 1920px

## Tests UI

Vérifier :

* loading ;
* empty state ;
* error state ;
* success state ;
* disabled state ;
* interactions tactiles.

## Règle

Une fonctionnalité ne doit pas être déclarée terminée uniquement parce que le scénario nominal fonctionne.
