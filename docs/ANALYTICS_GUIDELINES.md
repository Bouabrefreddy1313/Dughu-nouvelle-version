# DUGHU — Analytics Guidelines

## Objectif

Permettre de mesurer l'utilisation de Dughu sans collecter inutilement des données personnelles.

## Événements possibles

Selon les besoins du produit :

* inscription ;
* connexion ;
* publication ;
* like ;
* commentaire ;
* republication ;
* création de story ;
* consultation de story ;
* message ;
* recherche.

## Principes

Ne mesurer que les événements utiles.

Ne pas ajouter de tracking à chaque action sans raison.

## Confidentialité

Les données analytics doivent respecter les règles de confidentialité du projet.

## Performance

Le tracking ne doit pas ralentir l'application.

## Règle

Avant d'ajouter un nouvel événement analytics, identifier :

1. pourquoi il est nécessaire ;
2. quelle donnée est collectée ;
3. comment elle sera utilisée ;
4. si cette donnée est réellement nécessaire.
