# DUGHU — Privacy Guidelines

## Objectif

Protéger les données personnelles des utilisateurs.

## Principe de minimisation

Ne récupérer que les données nécessaires à une fonctionnalité.

## Données privées

Ne jamais exposer une donnée privée simplement parce qu'elle est disponible côté backend.

## Profil

Respecter les paramètres de visibilité définis par le produit.

## Messages

Les conversations doivent être accessibles uniquement aux utilisateurs autorisés.

## Logs

Ne pas enregistrer inutilement :

* mots de passe ;
* tokens ;
* données privées ;
* informations sensibles.

## Suppression

Lorsqu'une fonctionnalité de suppression de données existe, respecter les règles définies par le backend et le produit.

## Frontend

Ne jamais considérer qu'une donnée est sécurisée simplement parce qu'elle n'est pas affichée dans l'interface.

## Règle

Toute donnée privée doit être protégée côté serveur.
