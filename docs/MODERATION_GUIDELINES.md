# DUGHU — Moderation Guidelines

## Objectif

Préparer Dughu à gérer les contenus et comportements problématiques.

## Signalement

Prévoir lorsque la fonctionnalité est disponible :

* signalement d'une publication ;
* signalement d'un commentaire ;
* signalement d'un compte.

## Blocage

Un utilisateur doit pouvoir bloquer un autre utilisateur lorsque cette fonctionnalité est disponible.

## Modération

Les actions de modération doivent être contrôlées par les permissions appropriées.

## Suppression

Une suppression administrative doit respecter les règles du produit et être enregistrée lorsque nécessaire.

## Interface

Les actions sensibles doivent utiliser une confirmation claire.

## Confidentialité

Les données de signalement ne doivent pas être exposées inutilement aux utilisateurs.

## Règle

Ne jamais inventer une règle de modération qui n'est pas définie par le produit ou par les règles backend.
