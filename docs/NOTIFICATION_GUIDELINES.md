# DUGHU — Notification Guidelines

## Types

Les notifications peuvent concerner notamment :

* likes ;
* commentaires ;
* republications ;
* mentions ;
* nouveaux abonnements ;
* messages ;
* événements système.

## Principes

Une notification doit avoir une raison claire.

Éviter les notifications répétitives inutiles.

## Lecture

Le système doit permettre de distinguer les notifications lues et non lues lorsque cette fonctionnalité est prévue.

## Interface

Les notifications doivent être :

* responsive ;
* accessibles ;
* cohérentes avec l'identité Dughu.

## Erreurs

Une erreur lors du chargement des notifications doit afficher un message utilisateur personnalisé.

## Règle

Ne jamais créer une notification uniquement parce qu'un composant frontend a été affiché.
