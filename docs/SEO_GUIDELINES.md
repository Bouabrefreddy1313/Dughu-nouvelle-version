# DUGHU — SEO Guidelines

## Objectif

Optimiser les pages publiques de Dughu pour les moteurs de recherche.

## Metadata

Les pages publiques importantes doivent disposer de :

* titre ;
* description ;
* metadata appropriées ;
* Open Graph lorsque nécessaire.

## URLs

Les URLs doivent être :

* compréhensibles ;
* stables ;
* cohérentes.

## Pages privées

Les espaces privés du réseau social ne doivent pas être indexés inutilement.

## Partage

Les pages publiques importantes doivent prévoir une présentation correcte lors du partage sur les réseaux sociaux.

## Performance

Le SEO doit être considéré avec la performance et l'expérience utilisateur.

## Règle

Ne pas ajouter de SEO artificiel ou de contenu trompeur uniquement pour améliorer le référencement.
